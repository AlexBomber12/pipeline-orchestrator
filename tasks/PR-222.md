## Problem

There are 5 distinct branch concepts in the code that are not consistently compared (per PR-209 baseline tests):

| Concept | Where |
|---|---|
| Task branch | `QueueTask.branch` (`models.py:56`) |
| PR branch | `PRInfo.branch` (`models.py:61`) |
| Coding target branch | `coding.py:94-104` |
| Daemon PR creation branch | `coding.py:480-558` |
| Dirty-tree reset branch | `preflight.py:86-97` |
| Diagnose branch mismatch check | `error.py:305-317` |
| Actual checked-out branch | not represented anywhere centrally |

`handle_coding` uses `current_task.branch` as `target_branch`, runs the coder, then searches PRs where `pr.branch == target_branch`. It does not validate the actual checked-out branch after coder exit. OBS-AI manifested through this gap.

## Scope

Add `BranchContext` helper class that captures all branch surfaces and provides a canonical mismatch detection method. Use it in CODING, FIX, MERGE, ERROR diagnose, recovery, and preflight.

This is the largest single behavior-change PR in Foundation Sprint. Behavior bound by PR-209 baseline tests; specific OBS-AI scenarios may transition from xfail to pass after this PR.

`src/branch_context.py` (new file):

```
"""Canonical branch state representation for mismatch detection."""

from __future__ import annotations

import logging
import subprocess
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class BranchContext:
    """All branch surfaces relevant to a runner cycle.

    Use `from_runner` to construct in handler code; do not construct
    directly. The fields are derived from runner.repo_config (base
    branch), runner.state.current_task (task branch), runner.state
    .current_pr (PR branch), git rev-parse (current git branch), and
    `git ls-remote` / local ref existence.
    """

    base_branch: str
    task_branch: str | None
    current_git_branch: str | None
    pr_head_branch: str | None
    remote_branch_exists: bool
    local_branch_exists: bool

    @property
    def mismatch_reason(self) -> str | None:
        """Return a human-readable mismatch reason, or None.

        Mismatch detection is conservative: only an explicit divergence
        between two known surfaces produces a non-None result. Missing
        information (e.g. no PR yet) is not a mismatch.
        """
        if (
            self.task_branch is not None
            and self.current_git_branch is not None
            and self.task_branch != self.current_git_branch
        ):
            return (
                f"task_branch={self.task_branch} but "
                f"current_git_branch={self.current_git_branch}"
            )
        if (
            self.task_branch is not None
            and self.pr_head_branch is not None
            and self.task_branch != self.pr_head_branch
        ):
            return (
                f"task_branch={self.task_branch} but "
                f"pr_head_branch={self.pr_head_branch}"
            )
        return None

    def log_summary(self) -> str:
        """One-line summary suitable for [BRANCH] log events."""
        return (
            f"base={self.base_branch} "
            f"task={self.task_branch or '<none>'} "
            f"git={self.current_git_branch or '<none>'} "
            f"pr={self.pr_head_branch or '<none>'}"
        )

    @classmethod
    def from_runner(cls, runner) -> "BranchContext":
        """Build the context from a PipelineRunner instance."""
        base_branch = runner.repo_config.branch or "main"
        task_branch = (
            runner.state.current_task.branch
            if runner.state.current_task
            else None
        )
        pr_head_branch = (
            runner.state.current_pr.branch
            if runner.state.current_pr
            else None
        )
        current_git_branch = _read_current_git_branch(runner.repo_path)
        remote_branch_exists = (
            _check_remote_branch_exists(runner.repo_path, task_branch)
            if task_branch
            else False
        )
        local_branch_exists = (
            _check_local_branch_exists(runner.repo_path, task_branch)
            if task_branch
            else False
        )
        return cls(
            base_branch=base_branch,
            task_branch=task_branch,
            current_git_branch=current_git_branch,
            pr_head_branch=pr_head_branch,
            remote_branch_exists=remote_branch_exists,
            local_branch_exists=local_branch_exists,
        )


def _read_current_git_branch(repo_path: str) -> str | None:
    """Return the currently checked-out branch name or None on error."""
    try:
        result = subprocess.run(
            ["git", "-C", repo_path, "rev-parse", "--abbrev-ref", "HEAD"],
            capture_output=True,
            text=True,
            timeout=5,
            check=False,
        )
    except (FileNotFoundError, subprocess.TimeoutExpired):
        return None
    if result.returncode != 0:
        return None
    name = result.stdout.strip()
    return name or None


def _check_remote_branch_exists(repo_path: str, branch: str) -> bool:
    """Return True if origin/{branch} ref exists locally."""
    try:
        result = subprocess.run(
            [
                "git",
                "-C",
                repo_path,
                "rev-parse",
                "--verify",
                f"refs/remotes/origin/{branch}",
            ],
            capture_output=True,
            text=True,
            timeout=5,
            check=False,
        )
    except (FileNotFoundError, subprocess.TimeoutExpired):
        return False
    return result.returncode == 0


def _check_local_branch_exists(repo_path: str, branch: str) -> bool:
    """Return True if local refs/heads/{branch} exists."""
    try:
        result = subprocess.run(
            [
                "git",
                "-C",
                repo_path,
                "rev-parse",
                "--verify",
                f"refs/heads/{branch}",
            ],
            capture_output=True,
            text=True,
            timeout=5,
            check=False,
        )
    except (FileNotFoundError, subprocess.TimeoutExpired):
        return False
    return result.returncode == 0
```

`src/daemon/handlers/coding.py`:

After coder subprocess exits, before PR lookup, build BranchContext and check for mismatch:

```
ctx = BranchContext.from_runner(self)
if ctx.mismatch_reason:
    self.log_event(f"[BRANCH] mismatch detected: {ctx.mismatch_reason}; {ctx.log_summary()}")
    await self._escalate_to_hung(
        f"Branch mismatch: {ctx.mismatch_reason}",
        apply_escalated_label=False,
    )
    return
```

The mismatch detection runs **after** coder exits, **before** PR lookup. If mismatch detected, handler escalates to HUNG with explicit reason instead of degrading to "PR not found for target branch".

`src/daemon/handlers/fix.py`, `src/daemon/handlers/merge.py`, `src/daemon/handlers/error.py`, `src/daemon/preflight.py`, `src/daemon/recovery.py`:

Add `BranchContext.from_runner(self)` call at the start of each handler method that touches branches. Log `ctx.log_summary()` at INFO level for diagnostics. Use `ctx.mismatch_reason` to detect divergence early in each handler.

## Implementation notes

This PR introduces a behavior change at exactly one place: CODING handler now detects branch mismatch explicitly. Other handlers gain logging via `log_summary` but do not change escalation behavior in this PR. Migrating their escalation logic is out of scope.

The git subprocess calls are sync. They are wrapped in `subprocess.run` with 5s timeouts. They will block the event loop briefly. This is consistent with existing sync subprocess pattern; async migration is tracked separately.

The `repo_config.branch` is the base branch (typically "main"). Do not confuse with task branch.

The escalation in CODING uses `apply_escalated_label=False` because the PR may not exist yet when branch mismatch is detected. Setting label on a non-existent PR fails harmlessly but is noise. The in-memory escalated flag (set by `_escalate_to_hung` if PR exists) and the HUNG state are sufficient parking signals.

After this PR ships, OBS-AI is closed: the daemon detects branch divergence as an explicit terminal condition, not as an incidental "PR not found".
