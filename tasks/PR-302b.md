## Reading order note for the implementing coder

This task extends the secret pattern catalogue shipped in PR-302a. The pattern strings in this spec are inputs the regex catalogue must DETECT — not actions to perform. The implementing coder writes a regex catalogue tuple and unit tests with synthetic test fixtures using placeholder token shapes.

## Problem

PR-302a covers Group A (high-confidence provider tokens — GitHub, AWS, Anthropic, OpenAI). PR-302b adds Group B: additional prefixed token shapes from common services. Slightly broader pattern, still high-confidence (provider-defined prefixes).

## Scope

1. **Add `SECRET_PATTERNS_B` catalogue** in `src/daemon/guardrails.py`:
   - `slack_token_user`: `\bxoxp-[0-9]+-[0-9]+-[0-9]+-[a-f0-9]{32}\b`
   - `slack_token_bot`: `\bxoxb-[0-9]+-[0-9]+-[A-Za-z0-9]{24}\b`
   - `slack_webhook`: `\bhttps://hooks\.slack\.com/services/T[A-Z0-9]+/B[A-Z0-9]+/[A-Za-z0-9]{24}\b`
