## Problem

WATCH handler has the most complex throttle interaction: it both polls GitHub (subject to budget regimes) and may retrigger reviews per coder (subject to per-coder rate limit). Migration here is the last handler in the cutover series.

## Solution

Wrap each throttle decision in WATCH with `cfg.feature_flags.use_unified_inhibitor_check` conditional. Three decision points to migrate:

1. **Should we poll GitHub this cycle?** Unified: check GITHUB_BUDGET_PAUSE inhibitor; legacy: read github budget percent.
2. **Should we slow down polling?** Unified: check GITHUB_BUDGET_SLOWDOWN inhibitor; legacy: read percent threshold.
3. **Should we retrigger review with coder X?** Unified: `is_work_inhibited(state, coder=X)`; legacy: per-coder rate_limit check.

### Pattern

```python
if cfg.feature_flags.use_unified_inhibitor_check:
    blocked, blocking = is_work_inhibited(state, coder=None)
    if any(b.inhibitor_type == InhibitorType.GITHUB_BUDGET_PAUSE for b in blocking):
        return  # skip polling this cycle
    slowdown = any(b.inhibitor_type == InhibitorType.GITHUB_BUDGET_SLOWDOWN for b in blocking)
    poll_multiplier = 5 if slowdown else 1
    ...
else:
    # ... existing if-branches ...
```

For retrigger decision:

```python
if cfg.feature_flags.use_unified_inhibitor_check:
    blocked, _ = is_work_inhibited(state, coder=retrigger_coder)
    if blocked:
        return  # skip retrigger
```

## Threat model

**Threat addressed**: WATCH is the busiest handler (every active repo polls GitHub every cycle). Behavior drift here is the most visible to operators.

**Other layers protecting**: parametrized tests cover 3 throttle decisions × 2 flag states = 6+ scenarios.

**Why this layer needed**: final handler in the cutover. Without PR-330c, WATCH stays on legacy throttle checks while IDLE/PAUSED use unified - operators see mixed behavior depending on state.

### Caller audit

`handle_watch` callers per `grep`. Signature unchanged. The 3 throttle decisions all return bool to internal helpers; replacing the bool source preserves the decision tree.

GitHub budget regime is 3-state (pause/slowdown/normal). Legacy uses `if pct < 5: pause; elif pct < 20: slowdown; else: normal`. Unified maps to 2 different InhibitorType values plus absence. Test parametrization must cover the boundary edges (4.9%, 5.0%, 5.1%, 19.9%, 20.0%, 20.1%) to confirm no off-by-one in either path.
