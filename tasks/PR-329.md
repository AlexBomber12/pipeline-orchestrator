## Problem

Dispatcher currently fans out throttle checks across `handle_idle`, `handle_paused`, `handle_watch`. Each handler reads its own 4-8 Redis keys per cycle. With PR-328 populating `state.active_inhibitors`, a single helper can answer "is anything blocking?" given a candidate coder, eliminating the fanout.

This PR adds the helper behind a feature flag default-off so existing dispatcher paths stay live. PR-330 migrates the actual call sites under the flag.

## Solution

Add `is_work_inhibited(state: RepoState, coder: str | None = None) -> tuple[bool, list[WorkInhibitor]]` method or module function. Returns True if any inhibitor in `state.active_inhibitors` blocks now AND matches the coder filter (global inhibitors match any coder; per-coder inhibitors match only the specified coder).

Add `feature_flags.use_unified_inhibitor_check: bool = False` to RepoConfig. Helper consults this flag - when True, callers can use the helper for their decision; when False, callers should fall back to legacy if-branches. PR-330 wires the conditional.

### Helper sketch

```python
def is_work_inhibited(
    state: RepoState,
    coder: Optional[str] = None,
    now: Optional[datetime] = None,
) -> tuple[bool, list[WorkInhibitor]]:
    """Return (blocked, [inhibitors_that_block]).

    coder=None: match all inhibitors (global and per-coder).
    coder="claude": match global + claude-specific only.
    """
    from datetime import datetime as _dt, timezone
    current = now if now is not None else _dt.now(timezone.utc)
    blocking: list[WorkInhibitor] = []
    for inh in state.active_inhibitors:
        if not inh.is_blocking_now(current):
            continue
        if inh.is_per_coder() and coder is not None and inh.coder_affected != coder:
            continue
        blocking.append(inh)
    return (len(blocking) > 0, blocking)
```
