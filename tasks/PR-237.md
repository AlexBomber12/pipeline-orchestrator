## Problem

PR-219a/b shipped the `_transition_to_error` primitive and migrated 30+ callsites across `idle.py`, `coding.py`, `error.py`, `fix.py`, `merge.py`, `watch.py`, and `recovery.py`. PR-219b spec asserted a global invariant: after merge, `grep -rn "self\\.state\\.state = PipelineState\\.ERROR" src/daemon/` should return zero hits outside `_transition_to_error` itself.

The invariant is not satisfied. 4 inline writes remain in modules that were not in PR-219a/b explicit scope:

1. `src/daemon/handlers/hung.py:315` — exception handler when the fallback `gh_comments.post_comment("@codex review")` fails during HUNG escalation. Sets ERROR with `error_message = "post_comment failed: {exc}"`, logs `[ESCALATE] {exc}.`, returns without `publish_state`.
2. `src/daemon/runner.py:1639` — exception handler in `_run_cycle_body` when `ensure_repo_cloned` raises `RuntimeError`. Sets ERROR with `error_message = str(exc)`, logs `[INFRA] ensure_repo_cloned failed: {exc}.`, calls `publish_state`, returns.
3. `src/daemon/preflight.py:51` — exception handler in `preflight()` when `git_ops._git("status", "--porcelain")` raises `CalledProcessError`, `TimeoutExpired`, or `OSError`. Sets ERROR with `error_message = f"preflight failed: {exc}"`, logs `[INFRA] preflight failed: {exc}.`, returns False.
4. `src/daemon/preflight.py:69` — dirty working tree escalation in `preflight()` after `_DIRTY_CYCLES_BEFORE_AUTO_RESET` cycles fail to recover. Sets ERROR with `error_message = f"working tree dirty: {dirty}"`, logs `[INFRA] preflight: dirty working tree.`, returns False.

All 4 sites are functionally correct. They set `error_message`, emit an appropriately-prefixed `log_event`, and respect their callers' control flow. Migration is mechanical: replace the 3 to 4 lines per site with a single call to `await self._transition_to_error(...)` preserving identical behavior.

This PR closes the invariant gap so the assertion stated in PR-219b spec holds in production after merge.

## Scope

Migrate 4 callsites to `_transition_to_error`. Do not change behavior at any site. Do not touch any callsite outside this list.

After this PR ships, the invariant `grep -rn "self\\.state\\.state = PipelineState\\.ERROR" src/daemon/ | grep -v "_transition_to_error"` must return zero hits. Add the assertion to `tests/runner/test_transition_to_error.py` so future regressions are caught at CI time.

The 5 inline writes inside `runner.py::_transition_to_error` itself (lines 1024 in current code) are out of scope and stay as-is, since the primitive is the canonical writer.

    """Return ``True`` iff the working tree is clean."""

## Tests

`tests/runner/test_transition_to_error.py` already covers the primitive's contract under PR-219a/b. Extend it with a global-invariant assertion that fails CI if any future code reintroduces an inline ERROR write:

```
def test_no_inline_error_writes_outside_primitive():
    """Enforce the PR-219b global invariant repaired by PR-237.

    After PR-237 ships, no module under src/daemon/ should write
    ``state.state = PipelineState.ERROR`` directly. All ERROR
    transitions go through ``_transition_to_error``.

    The primitive itself contains the only legitimate inline write
    and is whitelisted by file path.
    """
    import pathlib
    import re

    daemon_root = pathlib.Path("src/daemon")
    pattern = re.compile(r"self\.state\.state\s*=\s*PipelineState\.ERROR")
    primitive_file = daemon_root / "runner.py"
    primitive_marker = "async def _transition_to_error"

    offenders: list[str] = []
    for path in daemon_root.rglob("*.py"):
        text = path.read_text()
        for lineno, line in enumerate(text.splitlines(), start=1):
            if not pattern.search(line):
                continue
            if path == primitive_file:
                # Whitelist the primitive itself (single legitimate write).
                preceding = "\n".join(text.splitlines()[: lineno])
                if primitive_marker in preceding:
                    continue
            offenders.append(f"{path}:{lineno}: {line.strip()}")

    assert not offenders, (
        "Direct ERROR writes found outside _transition_to_error:\n"
        + "\n".join(offenders)
    )
```

Existing tests under `tests/runner/test_state_transitions.py`, `tests/runner/test_recovery.py`, and any preflight-specific tests must continue to pass without modification, since this PR preserves behavior at each migrated site.

## Implementation notes

The `_transition_to_error` signature is:

```
async def _transition_to_error(
    self,
    message: str,
    *,
    save_run_record_as: str | None = "error",
    publish: bool = True,
    log_prefix: str = "[ERROR]",
    log_message: str | None = None,
) -> None:
```

For each migrated site, `save_run_record_as=None` is correct because all 4 sites are pre-task or infrastructure paths where no run record is in flight. The default value `"error"` would attempt to save a record against `None` task context and may error.

For `publish` parameter: match the original behavior site-by-site:
- preflight.py:51 → `publish=False` (original did not call `publish_state`)
- preflight.py:69 → `publish=False` (original did not call `publish_state`)
- runner.py:1639 → `publish=True` (original called `await self.publish_state()`)
- hung.py:315 → `publish=False` (original did not call `publish_state`)

For `log_message` parameter: use only when the original `log_event` text differs from `error_message`. preflight.py:51 and runner.py:1639 have different log/error text, so they need `log_message`. preflight.py:69 also needs it. hung.py:315 also needs it.

The `preflight()` method is `async def` already (verified in src/daemon/preflight.py:39), so `await self._transition_to_error(...)` is valid in both preflight migration blocks.

After all 4 migrations, run the new invariant assertion test locally before opening the PR. If it fails, the migration missed a site or introduced a new one; do not commit until it passes.
