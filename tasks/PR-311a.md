## Problem

Production scenarios where git history could be lost or corrupted (these are scenarios the backup feature MITIGATES):

1. **Force-push success against branch protection bypass** — operator account with admin rights force-pushes destructive history.
2. **Repository deletion via GitHub CLI** — accidental execution of repo-delete command.
3. **Disk corruption on the home server** — working clone goes bad; remote becomes only copy.
4. **Repository hijack via compromised credentials** — attacker rewrites history; restoring from offline backup is recovery mechanism.

The daemon's clone is not a backup — it tracks origin's HEAD. A genuine offline backup is a separate file produced by `git bundle create`, which packages all history into a single self-contained file.

PR-311a adds the bundle-creation primitive plus retention pruning, as an isolated module testable without daemon plumbing. PR-311b wires the module into the IDLE handler's periodic-task pattern (mirroring PR-300 main_commit_audit). Split rationale: bundle module is mechanically isolated and testable via tmp_path fixtures; the IDLE integration adds independent risk (cycle-counter behavior, config gating, log_event side effects) better reviewed separately.

Default-off. Operator opts in by setting `git_bundle_backup_enabled=True` and `git_bundle_backup_dir="/var/backups/orchestrator"` (or any writable path). Daily retention 7 = keep 7 most-recent daily bundles. Weekly retention 4 = keep 4 most-recent Sunday bundles. Retention 0 disables that tier.

### 2. New module `src/daemon/backups.py`

Two functions:

**`create_repo_bundle`** — async, returns Path on success or None on failure:

```python
async def create_repo_bundle(
    *, repo_path: str, repo_name: str, backup_dir: str,
) -> Path | None:
    """Create a git bundle of all branches and tags in the repo.

    Returns the bundle Path on success or None on failure. Uses
    ``git bundle create`` in a thread so the daemon event loop stays
    responsive during the (potentially slow) bundle write.
    """
```

Implementation:

1. Compute `backup_root = Path(backup_dir) / repo_name`.
2. `backup_root.mkdir(parents=True, exist_ok=True)`.
3. `timestamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")`.
4. `bundle_path = backup_root / f"{repo_name}-{timestamp}.bundle"`.
5. Inside `asyncio.to_thread(...)`:
   - Run `subprocess.run(["git", "bundle", "create", str(bundle_path), "--all"], cwd=repo_path, capture_output=True, text=True, timeout=300)`.
   - If returncode != 0, clean up partial bundle (`bundle_path.unlink(missing_ok=True)`) and return False.
   - Run `subprocess.run(["git", "bundle", "verify", str(bundle_path)], cwd=repo_path, capture_output=True, text=True, timeout=60)`.
   - If verify returncode != 0, clean up partial bundle and return False.
   - Return True.
6. On `subprocess.TimeoutExpired` or `OSError`, clean up partial bundle and return False.
7. After thread returns: if False, return None; else return `bundle_path`.

`--all` packages all branches and tags. Conservative choice — bundle is larger than a branch-scoped bundle but operator can recover any branch on restore. Storage estimate: ~5-20 MB per small repo.

**`prune_old_bundles`** — async, returns count of removed files:

```python
async def prune_old_bundles(
    *, backup_dir: str, repo_name: str,
    daily_retention: int, weekly_retention: int,
) -> int:
    """Remove bundles older than retention window.

    Returns count of files removed. Daily bundles kept = N most recent
    by mtime; weekly bundles kept = M most recent Sunday-dated bundles.
    Files matching neither retention list are removed.
    """
```

Implementation:

1. `backup_root = Path(backup_dir) / repo_name`.
2. If not `backup_root.exists()`, return 0.
3. List bundles: `sorted(backup_root.glob(f"{repo_name}-*.bundle"), key=lambda p: p.stat().st_mtime, reverse=True)` (newest first).
4. `keep = set()`. Add `bundles[:daily_retention]` to keep set.
5. Filter Sunday bundles: those where `datetime.fromtimestamp(b.stat().st_mtime, tz=timezone.utc).weekday() == 6`. Add `sunday_bundles[:weekly_retention]` to keep set.
6. For each `b in bundles`: if `b not in keep`, attempt `b.unlink()`. Count successes. Swallow OSError on unlink (best-effort).
7. Return removed count.

### 3. Tests

Create new test file `tests/test_backups.py` (uses pytest's `tmp_path` fixture):

- `test_create_repo_bundle_creates_valid_file`: init a small git repo in tmp_path via subprocess (`git init`, commit, etc), call `create_repo_bundle`. Assert returned path exists and `git bundle verify` against it exits 0.

- `test_create_repo_bundle_returns_none_for_non_git_directory`: tmp_path is an empty directory (no .git). Function returns None. No bundle file created in backup_dir.

- `test_create_repo_bundle_returns_none_on_subprocess_timeout`: monkeypatch `subprocess.run` to raise `subprocess.TimeoutExpired`. Function returns None. No partial file left in backup_dir.

- `test_create_repo_bundle_returns_none_on_verify_failure`: monkeypatch `subprocess.run` so the first call (create) succeeds but the second (verify) returns nonzero. Function returns None. The partial bundle file is removed.

- `test_create_repo_bundle_returns_none_on_oserror`: monkeypatch `subprocess.run` to raise `OSError("disk full")`. Function returns None. No partial file.

- `test_create_repo_bundle_filename_format`: successful create. Assert filename matches `{repo_name}-YYYYMMDDTHHMMSSZ.bundle`.

- `test_prune_old_bundles_keeps_daily_retention`: create 10 bundle files with descending mtimes (use os.utime to set). `daily_retention=3, weekly_retention=0`. Function removes 7, keeps 3 newest.

- `test_prune_old_bundles_keeps_sunday_for_weekly`: create bundles with mtimes spanning 2 weeks (mix of weekdays — include Sundays explicitly via os.utime). `daily_retention=2, weekly_retention=2`. Function keeps 2 newest by mtime + 2 newest Sundays. Note: if the 2 newest happen to be Sundays, the keep set overlaps — should be deduplicated via set semantics.

- `test_prune_old_bundles_zero_weekly_retention_removes_all_non_daily`: `weekly_retention=0, daily_retention=2`. Keeps only 2 newest, removes all others including Sundays.

- `test_prune_old_bundles_no_directory_returns_zero`: `backup_dir` does not exist. Function returns 0. No crash.

- `test_prune_old_bundles_empty_directory_returns_zero`: directory exists but contains no `.bundle` files. Returns 0.

- `test_prune_old_bundles_swallows_unlink_oserror`: monkeypatch `Path.unlink` to raise OSError. Function returns 0 (no successful removes) but does not crash.

## Implementation notes

`git bundle --all` includes all branches and tags. For repos with many feature branches this could grow large; if storage becomes an issue, a future PR can scope to `--branches main`.

The prune function uses mtime to determine recency. If operator manually copies bundles around (touching mtime), prune behavior may diverge. Acceptable for v1; document in operator setup docs (Sprint 17 Documentation Sprint scope).

Bundle verification at write time catches local corruption. Bundles that fail verify are deleted before the function returns — operator never sees partial files.

The `git_bundle_backup_dir` should be on a separate disk from the working clones for true defense-in-depth (so disk failure on the working volume doesn't take backups with it). Document this in operator setup docs.
