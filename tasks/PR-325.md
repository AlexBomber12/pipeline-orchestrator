## Problem

PR-322 introduced `subsource_registry` as the single source of truth for the 11 subsource strings. Nothing prevents a future PR from adding a 12th string literal somewhere in src/ (a new detector site, a new payload write, a new template branch) without registering it. The drift would silently break PR-323 dashboard filter (returns None for unknown), PR-324 badge (falls back to raw text), and any future registry-aware feature. The fix is a validation test that scans src/ for subsource-shaped string literals and asserts each is in the registry.

This same test also catches the inverse drift: a 12th registry entry with no actual usage anywhere in src/ (dead code in registry). Both directions are guarded.

## Solution

Add a new test module `tests/subsource_registry/test_completeness.py` with two assertions:

1. **String literal scan** — walk Python AST nodes in all `src/**/*.py` files, plus a text-scan of all `src/web/templates/**/*.html` files. Collect every string literal that matches the subsource shape (lowercase snake_case, 2-30 characters, not a common word like "todo" or "done"). Filter against an explicit allow-list of known sites where subsource strings appear (cancellation/storage.py, runner.py, dashboard.py, watch.py, repo_control.py, cancellation_card.html, migrations/). Assert every found literal is in `subsource_registry.all_subsources()`.

2. **Registry-vs-vocabulary alignment** — assert `subsource_registry.canonical_subsources() == src.cancellation.SUBSOURCE_VOCABULARY`. This is the formal contract that the 8 canonical entries stay in sync between the two surfaces.

The first test is the safety net for future PRs. The second is the contract assertion that PR-322 already enforces semantically; this codifies it as a test.

### Scanner approach

The AST scanner uses an explicit allow-list of source files where subsource strings legitimately appear, not a regex sweep over all of src/. Reasoning: subsource names overlap with English words ("crash", "guardrail") and a regex over all of src/ would generate false positives in unrelated contexts (log messages, exception types, etc). The allow-list is small and operator-maintained.

```python
from __future__ import annotations

import ast
from pathlib import Path

import pytest

from src.cancellation import SUBSOURCE_VOCABULARY
from src.subsource_registry import all_subsources, canonical_subsources

REPO_ROOT = Path(__file__).resolve().parents[2]

# Files known to emit or reference subsource string literals.
# Maintained alongside the registry: adding a new write site MUST add
# its source file here, and the test will catch its literals.
SUBSOURCE_SOURCE_FILES = [
    "src/cancellation/storage.py",
    "src/cancellation/__init__.py",
    "src/daemon/runner.py",
    "src/daemon/handlers/watch.py",
    "src/daemon/handlers/fix.py",
    "src/daemon/migrations/escalate_to_error.py",
    "src/daemon/migrations/hung_to_idle.py",
    "src/web/routes/repo_control.py",
    "src/web/routes/dashboard.py",
    "src/subsource_registry.py",
]

SUBSOURCE_TEMPLATE_FILES = [
    "src/web/templates/components/cancellation_card.html",
]


def _collect_python_string_literals(path: Path) -> set[str]:
    tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    found: set[str] = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Constant) and isinstance(node.value, str):
            found.add(node.value)
    return found


def _collect_template_subsource_branches(path: Path) -> set[str]:
    import re

    text = path.read_text(encoding="utf-8")
    pattern = re.compile(r"subsource\s*==\s*['\"]([a-z_]+)['\"]")
    return set(pattern.findall(text))


def test_canonical_subsources_match_vocabulary_frozenset():
    assert canonical_subsources() == SUBSOURCE_VOCABULARY


def test_every_python_subsource_literal_is_registered():
    registered = all_subsources()
    for relpath in SUBSOURCE_SOURCE_FILES:
        path = REPO_ROOT / relpath
        if not path.is_file():
            continue
        literals = _collect_python_string_literals(path)
        candidates = literals & registered
        if not candidates:
            continue
        for name in candidates:
            assert name in registered, (
                f"Subsource literal {name!r} found in {relpath} but missing "
                "from src.subsource_registry. Add it to the registry."
            )


def test_every_template_subsource_branch_is_registered():
    registered = all_subsources()
    for relpath in SUBSOURCE_TEMPLATE_FILES:
        path = REPO_ROOT / relpath
        if not path.is_file():
            continue
        names = _collect_template_subsource_branches(path)
        unknown = names - registered
        assert not unknown, (
            f"Template subsource branches in {relpath} reference unregistered "
            f"subsource names: {sorted(unknown)}. Add them to the registry."
        )


def test_every_registered_subsource_appears_in_source():
    """Inverse drift: every registry entry must be referenced somewhere.

    Catches dead registry entries — a name added to the registry with no
    write site or render branch backing it. If a subsource is registered
    but unused, either the write site was deleted (remove from registry)
    or this allow-list is missing the file (add the file).
    """
    registered = all_subsources()
    seen_in_python: set[str] = set()
    for relpath in SUBSOURCE_SOURCE_FILES:
        path = REPO_ROOT / relpath
        if not path.is_file():
            continue
        literals = _collect_python_string_literals(path)
        seen_in_python |= literals & registered
    seen_in_templates: set[str] = set()
    for relpath in SUBSOURCE_TEMPLATE_FILES:
        path = REPO_ROOT / relpath
        if not path.is_file():
            continue
        seen_in_templates |= _collect_template_subsource_branches(path)
    seen = seen_in_python | seen_in_templates
    unused = registered - seen
    assert not unused, (
        f"Registered subsources with no references in scanned files: "
        f"{sorted(unused)}. Either remove from registry or add the "
        "containing source file to SUBSOURCE_SOURCE_FILES or "
        "SUBSOURCE_TEMPLATE_FILES."
    )
```

### Plant test for safety net verification

Add one more test that monkey-patches the registry to inject a sentinel subsource and verifies the assertion fires:

```python
def test_plant_failing_case_fires_assertion(monkeypatch):
    """Verify the test actually catches drift, not just passes vacuously."""
    from src import subsource_registry

    real_lookup = subsource_registry.all_subsources

    def fake_lookup() -> frozenset[str]:
        # Remove "crash" from the set so any file using "crash" trips
        # the assertion. We pick crash because it appears in known files.
        return frozenset(s for s in real_lookup() if s != "crash")

    monkeypatch.setattr(subsource_registry, "all_subsources", fake_lookup)
    with pytest.raises(AssertionError, match="crash"):
        test_every_python_subsource_literal_is_registered()
```

## Threat model

**Threat addressed**: silent drift between registry and actual write/render sites. A future PR adding a 12th subsource without registering it would degrade dashboard filter (PR-323) and badge component (PR-324) without warning. This test makes that drift a CI failure.

**Other layers protecting**: type-checker catches some drift (`Literal["coder", "daemon", ...]` GroupBucket type rejects unknown buckets at registration time). But string literals at write sites are not type-checked against the registry; mypy cannot reach into a payload dict value.

**Why this layer needed**: the registry-vs-source contract is structural, not nominal. A name typo at a write site (`"crashe"` instead of `"crash"`) produces a silent miss in the dashboard filter unless this scanner catches it.

Maintenance note: the `SUBSOURCE_SOURCE_FILES` and `SUBSOURCE_TEMPLATE_FILES` allow-lists must be updated when new write sites or render branches are added in future PRs. Each future PR introducing a new subsource site must add the file to the allow-list as part of that PR.
