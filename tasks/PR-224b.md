## Problem

PR-224a created `tests/runner/` and moved 4 thematic groups (state transitions, error diagnosis, rate limit, recovery). This PR moves the remaining 3 groups plus the misc bucket, completing the split.

After both PRs ship, `tests/test_runner.py` is deleted entirely.

## Scope

Move the remaining tests from `tests/test_runner.py` into 3 more thematic files plus a misc bucket. Delete `tests/test_runner.py`.

## Files to modify

3 new files:

`tests/runner/test_branch_context.py`:
- Tests created by PR-209 (already in `test_runner.py` after PR-209 merges, will move now)
- Any other branch-mismatch tests

`tests/runner/test_publish_state.py`:
- All `test_publish_state_*`, `test_*_published_*`, `test_repo_state_*` tests
- Tests touching Redis state serialization

`tests/runner/test_config_reload.py`:
- All `test_reload_repo_config_*`, `test_*_config_dirty_*` tests
- Tests touching staged config and config_watcher interaction

`tests/runner/test_misc.py`:
- Anything that does not fit the 7 thematic buckets above
- Goal: this file should be small (under 1500 lines). If larger, the categorization needs refinement.

`tests/test_runner.py`:
- After all tests move out, delete the file. The package `tests/runner/` is the new home.

## Implementation notes

This is the cleanup PR for the test_runner split. No new categorization decisions — just the remaining tests.

If during the move you find a test in the misc bucket that fits one of PR-224a's thematic files (state transitions, error diagnosis, rate limit, recovery), move it to the right file from PR-224a rather than putting it in misc. Better to refine categorization once than leave misc oversized.

If `tests/runner/_helpers.py` was created in PR-224a, audit its usage after this PR. Helpers that are now used by tests in PR-224b's new files should remain in `_helpers.py`; helpers used only by one file should be inlined into that file.

After this PR, future PRs that touch `runner.py` should add tests to the matching thematic file in `tests/runner/`, not to a new top-level file.
