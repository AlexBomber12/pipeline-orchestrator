# PR-296: Repo card buttons fixed-position layout — Pause/Stop/Upload always at top-right corner

Branch: pr-296-repo-card-buttons-fixed-position
- Type: ux
- Complexity: low
- Depends on: none
- Priority: 2
- Coder: codex

## Problem

Dashboard repo cards render buttons (Pause / Stop / Upload) inside a flex container at `src/web/templates/components/repo_cards.html:85-109`. The container uses `flex w-full flex-wrap items-center justify-between gap-2 sm:w-auto sm:justify-end` which adapts position based on content width on the left side. When state badge changes ("CODING" vs "WATCH" vs "IDLE" — different lengths), or the repo name truncates differently, or the card width adjusts to viewport, the buttons jump horizontally.

Sprint 12 calibration session: Dashboard cards only (repo detail header is fine), all buttons in one row `Pause | Stop | Upload`, top-right corner of card, fixed position regardless of state badge width or content jitter. Per Aleksei 2026-05-06: "меняют позицию between active/paused/HUNG states, контент меняется в card buttons - и кнопки начинают прыгать" (historical quote referenced HUNG state pre-Phase-2; same jumping behavior applies now to active/paused/error transitions per Sprint 15b Phase 2).

## Scope

Layout changes in `src/web/templates/components/repo_cards.html` only:

1. **Move buttons block to absolute top-right of card.** Wrap the `<div class="flex w-full ...">` container at line 85-109 in a position-relative parent or use `position: absolute; top: 0; right: 0;` on the buttons block itself, with the card outer container marked `position: relative`. The buttons stick to top-right corner regardless of card content width.

2. **Force single-row layout for the three buttons.** Currently they are in `flex-wrap` which lets them wrap to a second line. Change to `flex-nowrap` with `gap-1` or `gap-2`. The buttons are small icons (h-8 w-8), so 3 in a row fits within typical card width without crowding.

3. **Ensure buttons always render in the same DOM order: Pause → Stop → Upload.** Currently `repo_controls` macro emits Pause/Stop in some order; verify by reading `_controls.html:26+`. The Upload button follows in the same flex container. If `repo_controls` emits a different order under different states (e.g., when paused, "Resume" replaces "Pause" — verify), keep the slot positions stable so the buttons don't shift.

4. **Use the global spinner from PR-294 for upload indicator instead of inline `_spinner.html`.** The `{% with spinner_id="upload-indicator-" ~ repo.name, spinner_label="Uploading..." %}` block at line 105-107 goes away. The upload form's `hx-indicator` attribute targets `#global-spinner` instead.
