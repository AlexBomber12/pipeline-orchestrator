3. Read `src/web/services/cancellation_view.py` (if exists) for context-prep layer between Redis and template

## Problem

`cancellation_card.html` currently switches on `cause.category` for 5 values (CRASH, ESCALATE, TIMEOUT, INFRA, NO_PUSH_DEADLOCK). After PR-315 migration, all records have `category="ERROR"` and the switch falls through to a generic "Unknown cancellation" path. Operator sees identical UI for crash vs review-timeout vs guardrail violation, losing forensic detail.

Additionally, historical records pre-dating the migration that contain `payload.legacy_category` for forensic context should be surfaced ("Originally classified as ESCALATE").

## Solution

Rewrite the template's switch logic:

```html
{% set subsource = cause.payload.get('subsource', '') %}
{% set legacy_category = cause.payload.get('legacy_category', '') %}

{% if subsource == 'crash' %}
    <span class="cause-badge cause-crash">Daemon crash</span>
    <p>Daemon process died mid-operation. {{ cause.payload.error_message }}</p>
{% elif subsource == 'review_timeout' %}
    <span class="cause-badge cause-stale">Stale review</span>
    <p>Codex did not respond within {{ cause.payload.elapsed_min }}m. Push a manual review or close the PR.</p>
{% elif subsource == 'fix_iteration_cap' %}
    <span class="cause-badge cause-deadlock">FIX iteration cap</span>
    <p>FIX cycle exceeded {{ cause.payload.iteration_count }} iterations without convergence.</p>
{% elif subsource == 'no_push_deadlock' %}
    ...
{% elif subsource == 'coder_escalate' %}
    ...
{% elif subsource == 'guardrail' %}
    ...
{% elif subsource == 'fix_idle_timeout' %}
    ...
{% elif subsource == 'infra_failure' %}
    ...
{% else %}
    {# Fallback: legacy_category for pre-migration records or unknown subsource #}
    {% if legacy_category %}
        <span class="cause-badge cause-legacy">Legacy: {{ legacy_category }}</span>
    {% else %}
        <span class="cause-badge cause-error">Error</span>
    {% endif %}
    <p>{{ cause.payload.error_message or cause.payload.reason_text or 'Cancellation reason not recorded.' }}</p>
{% endif %}
```

Style/CSS classes for each badge category remain consistent with current design tokens.

## Threat model

**Threat addressed**: operator loses forensic detail in dashboard after PR-315 category collapse.

**Other layers protecting**: payload.subsource preserves all detector context; payload.legacy_category preserves pre-migration category labels.

**Why this layer needed**: dashboard is operator's primary diagnostic interface; losing the subsource distinction would force operator to inspect Redis directly.
