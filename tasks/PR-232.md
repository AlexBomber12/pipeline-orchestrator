# PR-232: Fix select option colors in dark theme

Branch: pr-232-select-option-colors
- Type: bugfix
- Complexity: low
- Depends on: none
- Priority: 2
- Coder: claude

## Problem

In the Settings UI dark theme, native HTML `<select>` dropdowns show options with default OS colors (often white background with black text on macOS, regardless of theme). The styled select element has dark background but the dropdown options break the visual continuity.

UI-2: option colors should match the dark theme.

## Scope

Add CSS rules to style `<select>` option elements consistently with the dark theme.

## Files to modify

`src/web/templates/base.html` or the global stylesheet referenced by templates:

Add CSS:

```
/* PR-232: dark-theme select option styling */
select option {
    background-color: #1f2937; /* gray-800 */
    color: #e5e7eb;            /* gray-200 */
}

select option:checked {
    background-color: #374151; /* gray-700 */
    color: #ffffff;
}

select option:hover {
    background-color: #374151; /* gray-700 */
}
```

If the project uses Tailwind config, prefer extending the theme. Otherwise inline CSS in the global stylesheet works.

`src/web/templates/components/settings_coders.html`, `settings_daemon.html`, `settings_repo_list.html`:

Verify these templates use `<select>` elements and the new CSS reaches them. No template changes if CSS is global.

## Tests

This is a visual change; automated test coverage is limited.

`tests/e2e/`:

- Visual regression test (if Playwright supports screenshot comparison) for the Settings page select dropdowns.
- Functional test that selecting an option still submits correctly.

For tests in standard `tests/test_web_app.py`:

- Test the rendered HTML includes a `<style>` block with the new rules (or links to the stylesheet that has them).

## Implementation notes

Native `<select>` styling has limited cross-browser support. Some browsers (particularly Firefox on Linux) may ignore certain CSS rules on `<option>` elements. Document any known limitations in a comment near the CSS.

Alternative: replace native `<select>` with a custom dropdown component (e.g. `<details>` + styled list, or a JS library). This is heavier and out of scope for a P2 polish PR.

After this PR, dropdown options match the dark theme on Chrome and Safari (the operator's stated browsers per planning conversation). Firefox and Edge may have residual default styling; document as known issue if reproduced.
