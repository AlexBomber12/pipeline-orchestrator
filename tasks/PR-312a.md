# PR-312a: Bubblewrap sandbox helper module — pure-function builder for `bwrap` command line with allowlisted RW directories

## Reading order note for the implementing coder

This task implements a HELPER MODULE that constructs `bwrap` command lines as a list of strings. The Problem section below describes threat scenarios that motivate having this sandbox — these are scenarios the sandbox feature MITIGATES, not actions the implementing coder is being asked to perform. The implementing coder writes a Python helper module with one detection function and one builder function, plus unit tests. The implementing coder does not run any `bwrap` command, does not modify any coder dispatch path. PR-312b will integrate this helper into the dispatch path.

## Problem

Today the daemon spawns coder CLI processes (claude, codex) with full inherited filesystem access. This is too permissive — coder is bounded to "make changes inside this repo's working tree" but can read sensitive paths like `~/.ssh` or `~/.gitconfig`. PR-312a adds a pure-function helper that builds a `bubblewrap` command line wrapping the coder process with kernel-enforced filesystem restrictions. PR-312b will integrate this into actual coder dispatch.

bubblewrap (`bwrap`) is a setuid-free unprivileged sandboxing tool that uses Linux user namespaces and bind mounts to construct a filesystem view. Available in Ubuntu 22.04+ default repos.

## Scope

1. **New module `src/daemon/sandbox.py`** with two functions:

   ```python
   def is_bubblewrap_available() -> bool:
       """Return True if 'bwrap' executable is on PATH."""
       import shutil
       return shutil.which("bwrap") is not None

   def build_bwrap_command(
       *,
       command: list[str],
       repo_path: str,
       coder_config_dir: str | None = None,
       gh_config_dir: str | None = None,
       additional_rw_dirs: list[str] | None = None,
       additional_ro_dirs: list[str] | None = None,
   ) -> list[str]:
       """Construct a bwrap command-line wrapping the given inner command.

       Filesystem layout inside the sandbox:
       - / read-only bind mount of host /
       - <repo_path>: read-write bind mount (the coder's working tree)
       - <coder_config_dir>: read-write bind mount if provided (e.g., ~/.config/claude)
       - <gh_config_dir>: read-write bind mount if provided (e.g., ~/.config/gh)
       - /tmp: bwrap-managed tmpfs
       - additional_rw_dirs: each bound read-write
       - additional_ro_dirs: each bound read-only

       Returns the full bwrap argv. If bwrap is unavailable, returns the
       inner command unchanged (caller should check is_bubblewrap_available
       first if availability matters).
       """
   ```

2. **Implementation**:

   ```python
   def build_bwrap_command(*, command, repo_path, coder_config_dir=None,
                           gh_config_dir=None, additional_rw_dirs=None,
                           additional_ro_dirs=None):
       if not is_bubblewrap_available():
           return list(command)
       args = ["bwrap"]
       args.extend(["--ro-bind", "/", "/"])
       args.extend(["--proc", "/proc"])
       args.extend(["--dev", "/dev"])
       args.extend(["--tmpfs", "/tmp"])
       args.extend(["--bind", repo_path, repo_path])
       if coder_config_dir:
           args.extend(["--bind", coder_config_dir, coder_config_dir])
       if gh_config_dir:
           args.extend(["--bind", gh_config_dir, gh_config_dir])
       for path in additional_rw_dirs or []:
           args.extend(["--bind", path, path])
       for path in additional_ro_dirs or []:
           args.extend(["--ro-bind", path, path])
       args.extend(["--unshare-pid", "--unshare-uts", "--unshare-ipc"])
       args.extend(["--die-with-parent"])
       args.append("--")
       args.extend(command)
       return args
   ```
