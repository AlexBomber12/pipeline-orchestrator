## Problem

`src/github_client.py` is 1557 lines with 56 functions. It is a god adapter handling: gh wrapper, REST API, GraphQL, ETag cache, PR list, CI status, review status, reactions, comments, PR metadata, merge, rate-limit budget.

This is a mechanical split PR. No behavior changes; functions redistribute by API domain.

This PR is part 1 of 2. It creates the `src/github/` package and moves 4 high-traffic modules: `gh_runner`, `prs`, `checks`, `reviews`. PR-226b moves the remaining 4: `reactions`, `comments`, `rate_limit`, `cache`. Both PRs use a temporary backward-compat shim in `github_client.py` until PR-226b finishes the migration.

The split exists because moving 56 functions in one PR is one giant atomic change. If a single import path breaks anywhere in the codebase, the daemon fails to start. Two PRs each move ~28 functions and can verify daemon startup independently before continuing.

## Scope

Create `src/github/` package. Move 4 thematic modules. Keep a temporary `github_client.py` shim that re-exports from `src.github.*` so existing imports continue to work. Functions for `reactions`, `comments`, `rate_limit`, `cache` stay inside `github_client.py` until PR-226b.

## Implementation notes

`gh_runner.py` is the foundation — it has no inbound dependencies on other github modules. Move it first. The other 3 modules in this PR (`prs`, `checks`, `reviews`) all depend on `gh_runner`.

Modules NOT moved in this PR (`reactions`, `comments`, `rate_limit`, `cache`) may be referenced by the moved modules. If they are, the moved modules import from `github_client` directly:

```
# in src/github/prs.py
from src import github_client  # for not-yet-moved cache helpers
```

These imports will be updated in PR-226b to point to the new locations.

Tests: existing tests of GitHub client functions should pass without modification because public function signatures are unchanged. Internal helpers may need import path updates.

After this PR, `grep -rn "from src.github_client" src/` will return many hits; PR-226b reduces them to zero.
