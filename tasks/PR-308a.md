# PR-308a: Cascade ESCALATE detector core — Redis state, threshold-based detection function, daemon-loop integration

Branch: pr-308a-cascade-detector-core
- Type: feature
- Complexity: medium
- Depends on: PR-307, PR-320
- Priority: 1
- Coder: any

## Problem

Per-repo auto-pause from Phase 2 PR-285 has bounded blast radius — one repo paused does not affect others. When multiple managed repos accumulate ESCALATE causes simultaneously across a short window, the cause is usually systemic: rate limit exhaustion, GitHub API outage, network partition, daemon-side bug. Continuing to dispatch new tasks across remaining repos burns operator budget on work likely to also fail.

PR-308a adds the daemon-wide circuit breaker **detector and state**: when N+ repos accumulate ESCALATE causes within a sliding window, daemon enters PANIC mode and main loop skips per-repo dispatch. Operator-visible UX (dashboard banner, Resume button, webhook notification) is shipped in PR-308b.

## Scope

1. **Add Redis state helper** in `src/keyspace.py`:

   ```python
   def daemon_panic_state() -> str:
       """Daemon-global panic state record (not per-repo)."""
       return "daemon:panic_state"
   ```

2. **New module `src/daemon/cascade_monitor.py`** with `check_cascade_escalate_state(redis_client, app_config, log) -> bool`. Function:
   - Reads `app_config.daemon.cascade_escalate_threshold` (return False if 0 = disabled)
   - Computes `cutoff_ts = now - cascade_escalate_window_min * 60`
   - SCAN-iterates `cancellation_index:*` zsets, counts repos with at least one ESCALATE cause recorded since cutoff
   - If count ≥ threshold: writes JSON to `daemon:panic_state` key with `{enabled, reason, triggered_at, affected_repos, threshold_at_trigger}`. Returns True.
   - If count < threshold AND existing panic state exists with elapsed time ≥ `cascade_escalate_auto_resume_min`: deletes the key. Returns False.
   - If count < threshold AND existing panic state still within auto_resume window: returns existing.enabled value.

3. **Three config fields** in `src/config.py` daemon section:
   - `cascade_escalate_threshold: int = Field(default=3, ge=0, le=20)` (0 disables)
   - `cascade_escalate_window_min: int = Field(default=15, ge=1)`
   - `cascade_escalate_auto_resume_min: int = Field(default=60, ge=0)` (0 disables auto-resume)

4. **Wire into main daemon loop**: in `src/daemon/main.py`, before the per-repo dispatch loop iteration, call `check_cascade_escalate_state(...)`. If returns True, log `[PANIC] dispatch skipped for cycle` once, sleep `poll_interval_sec`, continue to next outer iteration.

5. **Tests** in `tests/daemon/test_cascade_monitor.py` (NEW file):
   - `test_check_below_threshold_returns_false`
   - `test_check_at_threshold_activates_panic`
   - `test_check_above_threshold_activates_panic`
   - `test_check_old_causes_outside_window_not_counted`
   - `test_check_disabled_when_threshold_zero`
   - `test_check_non_escalate_causes_not_counted`
   - `test_auto_resume_after_cooldown`
   - `test_no_auto_resume_when_disabled`
