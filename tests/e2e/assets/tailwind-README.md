# Tailwind browser fixture

`tailwind-3.4.17.js` is the unmodified Tailwind CSS 3.4.17 Play CDN runtime
retrieved from https://cdn.tailwindcss.com on 2026-11-09. The activity-feed
browser test serves it at the production script URL so its responsive layout
checks do not depend on CDN availability. Production assets are unchanged.

The upstream MIT license is in `tailwind-LICENSE`; bundled dependency notices
are retained in the JavaScript file.
